# The Coconut Shell

Welcome to The Coconut Shell, it's a shell build using Rust. My goal for this project is to know more about Linux
operating system--especially how the terminal works. Most of the time we just take for granted the feature of the
terminal in our Linux system. But under the hood there is actually fundamental yet fascinating concept that often
overlooked. Let's learn how Linux terminal works!

## Fascinating Concept

- Input parser and command tokenization
- Stdin, Stdout, and Stderr redirection
- Autocomplete and Trie data structure
- Spawning, curating and reaping background job
- Fork, Pipeline, and file descriptors __(very important)__

Those are the important point that caught my attention. Part of it haven't been finished yet, because I'm still working
on this project at my own pace. More stuff coming :)
